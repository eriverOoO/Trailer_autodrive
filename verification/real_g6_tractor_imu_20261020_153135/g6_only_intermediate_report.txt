1. USB 장치 역할 확정
사용자가 트랙터 IMU USB만 분리하고 G6는 유지했다고 명시.
전후 목록 대조: /dev/ttyUSB1 및 USB 3-8 by-path가 사라지고,
/dev/ttyUSB0 및 USB 3-7 by-path는 유지됨.
따라서 현재 물리 구성에서 다음과 같이 확정:
G6: /dev/ttyUSB0
  /dev/serial/by-path/pci-0000:80:14.0-usb-0:7:1.0-port0
  ID_PATH=pci-0000:80:14.0-usb-0:7:1.0, DEVPATH USB3/3-7.
트랙터 IMU: 분리 직전 /dev/ttyUSB1, USB 3-8.
  /dev/serial/by-path/pci-0000:80:14.0-usb-0:8:1.0-port0
  사용자에게 같은 USB 소켓으로 재연결 후 알려 달라고 안내. 현재 아직 분리 상태.
재연결 후 tty 번호는 반드시 다시 확인하며 이전 번호를 보장하지 않음.
양 변환기 VID10c4/PIDea60/serial0001 동일. by-id는 역할 고유 식별자로 쓰지 않음.
IMU 분리 뒤 by-id가 ttyUSB0으로 바뀐 것도 실제 확인됨.
/dev/imu_tractor 없음. udev 설치/변경, USB serial 변경 없음.
G6 명령은 물리 역할 확인 후 3-7 by-path로만 송신.
