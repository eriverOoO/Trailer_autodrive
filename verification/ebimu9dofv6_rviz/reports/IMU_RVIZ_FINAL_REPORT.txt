4. 패킷 파싱
현재 실시간 패킷 미검증.
과거 실제 raw 파일을 7byte씩 나눠 오프라인 처리: 399개 accepted, 0 rejected.
기존 AsciiParser의 모든 Quaternion과 1e-12 이내 일치.
실제 과거 wire: qz,qy,qx,qw,gx,gy,gz,ax,ay,az,timestamp_ms, *...CRLF.
ASCII checksum은 제조사 정의가 없어 N/A. Binary 파싱은 미구현, raw 저장만 가능.
형식이 다른 실제 입력은 거절하며 필드를 추측해 붙이지 않음.

5. 실제 출력 주파수

7. Quaternion·단위·시각
z,y,x,w -> x,y,z,w, norm 오차0.05 초과 입력 거절, 유효값 정규화.
과거 실측 raw norm 범위0.9999414532861411~1.0000224497480044.
deg/s -> rad/s. soa1의 body 중력 포함 g -> m/s²(9.80665).
공분산 미계측 항목은0(unknown), 미수신 gyro/accel은 covariance[0]=-1.
orientation 없는 패킷은 정상 Quaternion을 임의 생성하지 않고 거절함.
header는 호스트 parse/publication 시간이며 센서 동기 시각으로 주장하지 않음.
미래/오래된/역행 호스트 stamp, 잘못된 frame/Quaternion은 시각화 입력에서 거절.
센서 ms 역행/reset과 설정주기 대비 누락 추정은 별도 집계.
센서 내부 지연과 절대 자세 정확도는 미측정.

14. 문제 및 원인
- 물리 포트 식별: CP2102 정보만으로 G6와 IMU 구분 불가. 사용자 확인 대기.
- 과거0바이트 원인은 이번에 규명하지 못함. 전원/GND/TX 신호/장치 식별/
  출력모드/baud/점유/설정/하드웨어 순으로 실제 증거 확인이 필요함.
  센서 고장 또는 기존 코드 버그로 확정하지 않음.
- UART 레벨은 센서 VCC와 연동됨. CP2102 보드 VIO 허용치는 실물 미확인.
  배선 변경 또는 분리 작업을 수행·지시하지 않았음.
- RViz 글자 간격: Ogre가 공백을 과도하게 넓게 그려 문구가 화면 밖으로 벗어남.
  새 진단 코드에서 공백을 underscore로 바꿔 최종 GUI에서 정상 가독성 확인.
- 중간 GUI 반복시험에서 공백뿐인 Text Marker가 Ogre Vertex Buffer 오류를 유발.
  빈 줄은 DELETE로 변경, 최종 재시험에서 오류 없이 두 프로세스 생존 확인.
- RViz에는 TF 없음 경고 가능. Marker는 Fixed Frame 자체 좌표로 표시하며 TF 발행 없음.
- 원본 source_baseline.json은 src_example104개 경로가 현재 없어 불완전.
  원본 폴더 mtime16:12는 이번 작업 시작19:59보다 앞섬. 경로를 복원하지 않음.
