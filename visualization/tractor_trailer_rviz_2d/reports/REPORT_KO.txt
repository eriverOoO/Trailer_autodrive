9. 최초 기준 및 phi
사용자가 두 차체가 일직선·정지 상태임을 확인한 뒤 align_straight SetBool true 요청.
양쪽 수신 LIVE, 실측 기하와 mounting/sign 확인, 최근0.3초 정지 조건이 모두 필요.
초기 yaw는 각각 다른 센서 절대값이어도 따로 기록하고 변화량을 계산.
동일한 host timestamp 시각의 두 unwrapped yaw와 SLAM pose를 보간. extrapolation 없음.
최신 IMU timestamp 차이 기본50ms 초과 시 유효 phi를 만들지 않음.
phi = wrap(trailer_yaw - tractor_yaw), 범위[-pi,pi).
예: tractor+30deg / trailer+10deg -> phi=-20deg. 원본과 동일하며 이전 3D 예시 부호와 다름.
통신 gap/reset/INVALID 후 기준 epoch가 바뀌면 ALIGNMENT LOST, 수동 재정렬 필요.
기본은 AHRS orientation. gyro_z는 명시적 source 선택·bias 확인이 필요하고 적분 drift를 포함.
브리지 header는 host 수신 시각이며 센서 내부 시간의 물리 동기화/전송 지연 보정은 미검증.

16. 종료 및 원복
새 Launch 터미널 Ctrl+C. 시작한 시험 프로세스는 이번 작업 종료 전에 정리됨.
기존 G6/Cartographer/실차 실행 스크립트·기본 동작을 바꾸지 않아 설정 복원 작업이 필요 없음.
기존 시스템은 기존 명령 그대로 실행. 새2D Launch를 종료하면 새Marker는0.8초 이내 만료.
이전3D 패키지는 보존됨. 별도로 이전3D Launch를 실행하지 않는 한 새2D 화면에3D가 나타나지 않음.

17. 미해결/추가 하드웨어 작업
- CP2102 물리 역할 식별, 실제 두 번째 IMU 및 G6 연결 확인.
- 각 실제 UART RX/형식/Hz, 두 센서 frame/장착축/수직Z/좌우sign 확인.
- 실제 추적 기준점과 rear axle/hitch/trailer axle 기하 실측.
- 초기 일직선 기준 및 실제 map 방향 정렬.
- 실제 두 IMU 단독·동시·같은각도·복귀·중단 실험, host/sensor 지연과 drift 측정.
- 실제 /map, /scan 표시와 Cartographer pose source TF의 갱신·정상성 확인.
그 전까지 실제 하드웨어 통합은 미완료이며 코드/디자인 시험 통과와 구분한다.
