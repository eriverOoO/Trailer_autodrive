# 2026-11-18 카메라·LiDAR 손밀기 테스트

흰색 소형 차체를 관찰하며 우리 차량을 손으로 밀어 상대 차의 오른쪽으로 이동하는 현장 시험 기록입니다.
모터 명령을 발행하지 않았습니다. 센서 스트림에서 약 20초 동안 받은 실제 데이터입니다.

- 이미지: `image_0000.jpg` ~ `image_0042.jpg`, 총 43장, 약 2Hz로 추출한 C920 영상.
- 스캔: `measurements.jsonl` 안의 `type: scan` 레코드 232개, 약 11.7Hz.
- 카메라 프레임: `parking_left_camera_optical_frame`.
- 스캔 프레임: `laser_frame`. 메시지당 점 개수 중앙값 1,545개.
- 레코드 전체 헤더 시각 범위: 약 19.96초.

`measurements.jsonl`은 이미지 메타데이터와 스캔을 수신 순서대로 섞어 기록한 JSON Lines 파일입니다.
이미지 행의 `file`은 이 폴더 안의 JPEG를 가리킵니다. `stamp_ns`는 각 메시지의 ROS 헤더 시각입니다.
스캔 행의 거리 단위는 m, 각도 단위는 rad이며, 거리 배열의 무한대/NaN은 null로 저장했습니다.
`angle_min`, `angle_increment`, `range_min`, `range_max`, `scan_time`, `time_increment`를 함께 보존했습니다.

## 관찰 결과와 한계

영상에서 흰 차체의 옆면이 관측됐으며 LiDAR에도 주변 반사점이 들어왔습니다.
카메라–LiDAR 실측 공간 보정과 하드웨어 시각 동기화는 수행하지 않았습니다.
점무리가 차체인지 받침대인지 확정한 데이터 또는 정답 라벨은 없습니다.
카메라 시각은 이미지 발행 시각이므로 정확한 노출 시각으로 해석하면 안 됩니다.
LiDAR의 한 회전은 약 86ms에 걸치며 손으로 미는 동안의 운동 왜곡은 보정하지 않았습니다.

당시 실시간 MobileNet-SSD 화면은 소형 차체를 비행기/의자로 오인식했습니다.
이 기록에는 인식 결과나 박스가 아닌 원본 영상·스캔만 저장돼 있습니다.
이 데이터를 차 인식 또는 자동 물체 대응 성공의 근거로 사용하지 않습니다.

도구 실행과 저장 형식은 `../../../tools/SENSOR_COMPARE.md`를 참고하세요.
모델 가중치는 포함하지 않으며 `tools/setup_sensor_compare_model.sh`로 받을 수 있습니다.
